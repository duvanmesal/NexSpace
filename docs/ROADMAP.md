# Roadmap y autorizaciones

Actualizado: 2026-10-11. La especificación v0.4 conserva su contexto histórico; las autorizaciones posteriores se registran aquí y en AGENTS.md.

- Fase 0: cierre condicionado; FLOATING base funcional, DESKTOP experimental y deshabilitado.
- Fase 1: aceptada por el usuario con alcance condicionado. No desaparecen los pendientes de gesto físico Explorer→NexSpace, accesibilidad, DPI/multimonitor, translucidez, animaciones y perfilado de memoria. Evidencia en PHASE1_VALIDATION.md.
- Fase 2: implementación integrada entregada para revisión; NexDock y NexManager en el mismo proceso, servicios y SQLite v2. Restore/Debug/Release y 24 unitarias + 21 de integración por configuración PASS; recorridos nativos y pendientes en PHASE2_VALIDATION.md. No registrar inicio con Windows automáticamente. Commits de esta fase locales hasta revisión; no se declara aceptación integral. Auto-ocultamiento y bandeja no implementados.
- Fase 3: no autorizada. Perfiles múltiples, editor avanzado y operaciones físicas sobre archivos fuera de esta entrega.
