2. `concepts/01_A_contenedores_integrados.png`: contenedores distribuidos sobre el escritorio.

4. `concepts/03_C_sistema_hibrido_APROBADO.png`: **REFERENCIA PRINCIPAL DEL PRODUCTO**. Combina paneles plegables y dock flotante inferior con menú emergente.

## Instrucciones a Codex
- Priorizar **C**. A y B muestran características individuales, pero NO reemplazan la decisión híbrida.
- Mantener el centro del fondo despejado, paneles compactos, bordes redondeados, efecto vidrio oscuro y dock discreto.
- Estos diseños son ilustraciones generadas por IA; sus iconos, textos, proporciones, nombres y posiciones no son requisitos exactos.
- No usar el bitmap completo como interfaz, no extraer iconos de apps ajenas para redistribuir.
- Implementar controles reales accesibles y adaptables a DPI, dimensiones de pantalla y temas.
- La captura original contiene nombres de programas y archivos personales. No subirla públicamente sin permiso.
- Las imágenes son referencias visuales para diseño, NO pruebas de funcionalidad.
